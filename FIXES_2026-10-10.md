# StreamFlix targeted fixes — October 10, 2026

1. Admin archive now includes both inactive titles and soft-deleted titles. Restoring sets `is_active=true` and clears `deleted_at`. The UI refreshes archive/catalog after toggling status.
2. Review creation and editing check a starter list of offensive language on the backend. Rejected review requests return HTTP 400; this is a basic keyword filter, not comprehensive moderation.
3. Deactivating a title hides it from client playback and moves it into the Admin Archived Content listing; reactivating it restores the title, subject to valid licensing.
4. Checked `is_kids_suitable` titles are eligible for kids profiles if their age rating is G, TV-Y, TV-Y7, TV-Y7-FV, TV-G, U, ALL, 0+, 6+, 7+, or PG. Adult age ratings remain blocked even if accidentally approved. Unchecked titles do not appear in kids profiles.
5. Checkout phone input strips non-digits and only accepts 10–15 digits, with the same check enforced by the backend COD/Card checkout endpoints. Names and addresses still permit letters (as required).
6. Narrow Admin layout uses document scrolling with mouse wheel / trackpad / touch instead of clipping the main content.
